隐私政策

KNEXM Co., Ltd. · 生效日期 2026年11月1日

本页为方便阅读而提供的译文。如内容有出入，以韩文版本为准。

KNEXM Co., Ltd.（以下简称“本公司”）重视用户的个人信息，并遵守韩国《个人信息保护法》等相关法律法规。本政策说明在本公司网站（knexm.com）及咨询过程中，个人信息是如何被处理的。

1. 收集的个人信息

在您通过邮件、电话咨询或使用本网站时，本公司可能会获取以下信息。

  • 邮件咨询：姓名、邮箱地址、联系方式、咨询内容（由您主动发送的信息）
  • 网站访问记录：IP 地址、浏览器类型、访问时间（由托管服务自动记录）

本网站没有会员注册、登录或支付功能，本公司也不使用自有 Cookie 或访客追踪工具。

2. 使用目的

所获取的个人信息仅用于以下目的。

  • 确认并回复咨询及合作提议
  • 维护网站的稳定运行与安全

3. 保存与销毁

个人信息在达到使用目的后将立即销毁。但如相关法律要求保存一定期限，将在该期限内安全保管后再行销毁。电子文件以无法恢复的方式删除，纸质文件则予以粉碎或焚毁。

4. 向第三方提供

本公司不会向第三方提供用户的个人信息。但法律另有特别规定，或侦查机关依法定程序提出要求的情形除外。

5. 委托处理

本网站通过 GitHub, Inc. 的 GitHub Pages 运营，访问记录可能会保存在 GitHub 的服务器（韩国境外）上。此外，本网站从 jsDelivr 加载字体，并在交通指南页面显示 Google 地图，因此在打开页面时，IP 地址等基本连接信息可能会传送至这些服务。各服务对个人信息的处理遵循其各自的政策。

6. 用户的权利

用户可随时要求查阅、更正、删除或停止处理其个人信息。请通过以下联系方式提出，我们将及时处理。

7. 个人信息保护负责人

  • 公司名称：KNEXM Co., Ltd.（케이넥스엠주식회사）
  • 负责人：Yoon Yeoul（代表）
  • 邮箱：info@knexm.com
  • 电话：1688-5372（仅限韩国境内）

8. 政策变更

本隐私政策自2026年11月1日起生效。如有变更，将通过本网站进行通知。
