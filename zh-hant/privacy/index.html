隱私權政策

KNEXM Co., Ltd. · 生效日期 2026年11月1日

KNEXM Co., Ltd.（以下簡稱「本公司」）重視使用者的個人資料，並遵守韓國《個人資訊保護法》等相關法令。本政策說明在本公司網站（knexm.com）及洽詢過程中，個人資料是如何被處理的。

1. 蒐集的個人資料

在您透過電子郵件、電話洽詢或使用本網站時，本公司可能會取得以下資訊。

  • 電子郵件洽詢：姓名、電子郵件地址、聯絡方式、洽詢內容（由您主動傳送的資訊）
  • 網站存取紀錄：IP 位址、瀏覽器類型、存取時間（由託管服務自動記錄）

本網站沒有會員註冊、登入或付款功能，本公司也不使用自有 Cookie 或訪客追蹤工具。

2. 使用目的

所取得的個人資料僅用於以下目的。

  • 確認並回覆洽詢及合作提案
  • 維護網站的穩定運作與安全

3. 保存與銷毀

個人資料在達成使用目的後將立即銷毀。但如相關法令要求保存一定期間，將於該期間內安全保管後再行銷毀。電子檔案以無法復原的方式刪除，紙本文件則予以碎紙或焚毀。

4. 提供予第三方

本公司不會將使用者的個人資料提供予第三方。但法令另有特別規定，或偵查機關依法定程序提出要求者除外。

5. 委託處理

本網站透過 GitHub, Inc. 的 GitHub Pages 營運，存取紀錄可能會保存在 GitHub 的伺服器（韓國境外）上。此外，本網站從 jsDelivr 載入字型，並於交通指南頁面顯示 Google 地圖，因此在開啟頁面時，IP 位址等基本連線資訊可能會傳送至這些服務。各服務對個人資料的處理依其各自的政策辦理。

6. 使用者的權利

使用者可隨時要求查閱、更正、刪除或停止處理其個人資料。請透過以下聯絡方式提出，我們將盡速處理。
